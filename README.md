# TIKOn Kesäkalenteri 2026

Avaa `index.html` selaimessa tai julkaise kansio GitHub Pagesissa.

## Tiedostot
- `index.html`
- `style.css`
- `script.js`

## Käyttö
1. Avaa `index.html` selaimessa.
2. Kalenteri rakentuu automaattisesti.
3. Luukut avautuvat vain silloin kun niiden viikko on alkanut.
4. Kirjoita `TIKO` löytääksesi easter eggin.

## GitHub Pages
1. Lataa koko kansio GitHubiin.
2. Ota Pages käyttöön branchista `main` ja root-kansiosta.
3. Avaa julkaistu linkki.

## Huomio
Tässä versiossa kuvat tulevat ulkoisista URL-osoitteista, joten verkkoyhteys tarvitaan niiden lataamiseen.
